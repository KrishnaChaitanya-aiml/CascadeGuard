# Data Sources Used / Evaluated

## Core

- GDACS API: https://www.gdacs.org/gdacsapi/swagger/index.html
- OpenStreetMap Overpass API: https://wiki.openstreetmap.org/wiki/Overpass_API
- Open-Meteo Historical Weather API: https://open-meteo.com/en/docs/historical-weather-api
- Open-Meteo Global Flood API: https://open-meteo.com/en/docs/flood-api
- WorldPop WOPR API: https://apps.worldpop.org/woprVision/woprAPI.html
- USGS Earthquake Catalog API: https://earthquake.usgs.gov/fdsnws/event/1/wsdl
- geoBoundaries API: https://www.geoboundaries.org/api.html
- Nominatim: https://nominatim.org/release-docs/latest/api/Search/

## Optional enrichment connectors

- NASA FIRMS: https://firms.modaps.eosdis.nasa.gov/api/
- NOAA IBTrACS: https://www.ncei.noaa.gov/products/international-best-track-archive
- ReliefWeb API: https://apidoc.reliefweb.int/
- Copernicus EMS: https://mapping.emergency.copernicus.eu/

Always follow the provider's attribution, rate-limit and credential requirements.
